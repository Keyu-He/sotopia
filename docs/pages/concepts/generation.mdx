# Overview

The core of generating agent action and environment observation lies in the [`agenerate`](/python_API/generation_utils/generate#ageneratemodel_name-str-template-str-input_values-dictstr-str-output_parser-baseoutputparseroutputtype-temperature-float--07-structured_output-bool--false---outputtype) function,  which is versatile by taking the `output_parser` as an argument and returning the output in the desired format.

<Callout type="info" emoji="ℹ️">
  Structured output is used to return the output in a structured format, such as a dictionary or a Pydantic object.
  Currently, the structured output is only supported for the models below:
    * `gpt-4o-mini-2024-07-18` and later
    * `gpt-4o-2024-08-06` and later

The `bad_output_process_model` is used to process the bad output. `DEFAULT_BAD_OUTPUT_PROCESS_MODEL` is set to be `gpt-4o-mini` (At the publication time of Sotopia, we used `gpt-3.5-turbo-0613`. However this model has been taken off the shelf by OpenAI.).

The `use_fixed_model_version` is used to determine whether to use the fixed model version. If set to `True`, the model version will be fixed to the version that was used in Sotopia paper. If set to `False`, the model version will be the latest version available.

Warning: As some fixed model versions might not be available in the OpenAI API, setting `use_fixed_model_version = True` might result in an error.

</Callout>

Here is an example of how to use the `agenerate` function:

### Generate the first N prime numbers

```python
from sotopia.generation_utils.generate import ListOfIntOutputParser, agenerate

async def generate_first_N_prime_numbers(n: int) -> list[int]:
    return await agenerate(
        model_name="gpt-4o",
        template="Generate the first {n} prime numbers.",
        input_values={"n": str(n)},
        output_parser=ListOfIntOutputParser(n),
    )
```

The input to `agenerate` are the following:

- `model_name`: The name of the model to use.
- `template`: The template to use. You can use `{}` to add the input variables.
- `input_values`: The input values to the template. The keys should be the same as the variables in the template.
- `output_parser`: The output parser to use. The output parser should be a subclass of `BaseOutputParser`.

In this example, we generate a list of the first `n` prime numbers with the `gpt-4o` model. The `ListOfIntOutputParser` is used to parse the output into a list of integers.

### Using Local and Custom Models

Apart from using API endpoints from LLM providers like OpenAI, Together AI, Azure, etc., you can also use local models and custom models with OpenAI-compatible endpoints. Sotopia supports multiple local model serving options:

#### 1. Ollama Models

[Ollama](https://ollama.ai) provides an easy way to run open-source LLMs locally. LiteLLM has native support for Ollama.

**Format:** `ollama/<model_name>` or `ollama/<model_name>@<url>`

**Example:**
```python
model_name="ollama/llama3.2:1b"  # Uses default Ollama port
# OR with custom URL:
model_name="ollama/llama3.2:1b@http://localhost:11434"
```

**Environment Variables:**
- `OLLAMA_BASE_URL`: Set custom Ollama server URL (default: uses LiteLLM's default)
- `OLLAMA_API_KEY`: Set API key if needed

For more information, check out `examples/generation_api/ollama_model.py`.

#### 2. LM Studio

[LM Studio](https://lmstudio.ai) is a desktop application for running local LLMs with a user-friendly interface.

**Format:** `lmstudio/<model_name>` or `lmstudio/<model_name>@<url>`

**Example:**
```python
model_name="lmstudio/local-model"  # Uses default LM Studio port
# OR with custom URL:
model_name="lmstudio/llama-3.2-1b@http://localhost:1234/v1"
```

**Environment Variables:**
- `LMSTUDIO_BASE_URL`: Set custom LM Studio server URL (default: `http://localhost:1234/v1`)
- `LMSTUDIO_API_KEY`: Set API key if needed (default: `lm-studio`)

For more information, check out `examples/generation_api/lmstudio_model.py`.

#### 3. Generic Local Models

For other local model servers with OpenAI-compatible APIs (e.g., vLLM, LocalAI, FastChat, Text Generation WebUI):

**Format:** `local/<model_name>` or `local/<model_name>@<url>`

**Example:**
```python
model_name="local/meta-llama/Llama-3.2-1B"  # Uses default local server
# OR with custom URL:
model_name="local/meta-llama/Llama-3.2-1B@http://localhost:8000/v1"
```

**Environment Variables:**
- `LOCAL_MODEL_BASE_URL`: Set custom local server URL (default: `http://localhost:8000/v1`)
- `LOCAL_MODEL_API_KEY`: Set API key if needed (default: `local`)

For more information, check out `examples/generation_api/local_model.py`.

#### 4. Custom Models with LiteLLM Proxy

If you host a model on [LiteLLM](https://github.com/BerriAI/litellm) proxy server or another OpenAI-compatible endpoint:

**Format:** `custom/<model_name>@<url>`

**Example:**
```python
model_name="custom/llama3.2:1b@http://0.0.0.0:4000"
```

**Environment Variables:**
- `CUSTOM_API_KEY`: Set the API key for your custom model

For more information, check out `examples/generation_api/custom_model.py`.
